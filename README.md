# Site da Shield Soluções Financeiras

Site estático publicado pelo GitHub Pages em https://shieldcredito.com.br.
Os arquivos desta branch são gerados; o código-fonte e o gerador ficam na branch `fonte` (`python3 build/build.py prod`).

## Blog (/conteudo/)

Os artigos ficam em `_blog/posts/*.md` e são gerados com `python3 _blog/build.py` (direto nesta branch).
Plano, cadência e regras em `_blog/PLANO.md`.
